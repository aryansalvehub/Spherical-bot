# Spherical-bot
Our project is a wireless spherical robot. The robot is built to tackle challenging terrain while maintaining stability, agility, and precise manual control. 
This robot is a wireless sphere robot built for stable, agile, and accurate movement through rough terrains. The sphere shape of this robot makes it capable of moving through rocks, sand, rough terrains, hills, speed bumps, narrow pathways, and sharp turns. This robot can be controlled through a wireless joystick controller. There is an efficient and powerful drive mechanism in the robot with adequate power supply inside and also there are some wheels with good traction. The focus on this robot was on balancing, making the robot light, and having good power and control on the robot. This robot has a protective spherical outer surface to make it capable of moving in any direction without hurting the internal components. The mechanical design, electronics, wireless connection, and control systems are integrated together to build this robot.
